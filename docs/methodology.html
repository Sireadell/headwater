Honesty table

What’s real, what’s simplified and disclosed, and what isn’t built yet. Plain statements, checkable in the code itself, not buried in comments.

Real
ERC-8004 registry reads
Calls the actual Identity and Reputation registries live on Monad mainnet. Function signatures pulled from the reference contracts, not the spec doc.
Funding-provenance signal
Reads real Monad AUSD transfer events, verified against real wallets and real on-chain transactions. Live counts at the time of writing: 283 circular-funding pairs and 546 fan-out funders detected across the indexed set.
Automated review timing
Measures how ragged the gaps are between a wallet’s consecutive reviews. People review at irregular intervals, minutes then hours then days; a script does not. The measure is the coefficient of variation, which is scale-free, so it catches a bot firing every 50 seconds and one firing every 50 minutes alike. It only fires on 5 or more intervals, so a short uniform run is not enough. Zero-second gaps from reviews sharing a block are excluded, since counting them would manufacture a perfect score.
Deep per-wallet funding history
The live index only covers a recent block window, which a patient attacker could fund around. So the first time a wallet appears as a reviewer, its full AUSD history is pulled on demand via HyperSync and fed through the same checks. Verified working: transfers from ~49 million blocks before the live window are present in the data.
9 detection signals
106 automated tests passing, covering every funding-relationship and reputation-overlap check the tool runs.
Simplified, disclosed not hidden
Token coverage
Tracks AUSD, the stablecoin real agents use to pay each other on Monad today. Native MON transfers are not yet indexed — a funder paying in native MON is currently invisible to this tool.
Not built yet
Wallet reputation labels
Previously described here as working. It is not. The code path exists but points at an endpoint that returns 404, and no API key is configured, so not a single wallet has ever been screened against exchange or institutional labels. The lookup page now reports this as NOT ACTIVE rather than showing an empty result as if it were a clean pass. Corrected on 2026-09-21 after checking the live table and finding it empty chain-wide.
Agent Wallet hook
The gap it would fill is real and documented, but no code exists for it yet. This is what would make Headwater infrastructure other apps call, not a standalone checker.
Registering Headwater as a listed agent
Requires a funded wallet and a live on-chain transaction. Not registered yet.
