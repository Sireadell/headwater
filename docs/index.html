ERC-8004 reputation context · Monad mainnet

A reputation score is a number with no units.

ERC-8004 gives an agent a score, and Monad’s own docs tell agents to check it before a high-value transaction. Nothing tells you what that score is made of. Headwater indexes every agent on Monad and traces the funding behind every reviewer, so you can see whether a score is broad, thin, self-written, campaign-funded or produced by a game.

Measured live on Monad mainnet, 2026-10-08, across all 10,324 registered agents. None of this is an accusation. A funded campaign can be a legitimate quest, and a game contract reporting wins and losses is the standard working exactly as designed. The point is that all six of these render as the same kind of number in a registry, and nothing today tells them apart. The badges here are the same words the lookup page, the JSON API and the MCP server use, so nothing on this site calls the same thing by two names.
